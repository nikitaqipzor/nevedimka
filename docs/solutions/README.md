# Solutions Notes

Use this folder for short, reusable solution notes.

## Rules
- Keep notes short.
- Capture reusable patterns, not task-by-task noise.
- Do not store secrets, tokens, private customer data, or raw sensitive logs.
- If a solution note conflicts with `PROJECT.md`, `docs/ARCHITECTURE.md`, `docs/DECISIONS.md`, or `SECURITY.md`, those source-of-truth docs win.

## Good Uses
- Reusable debugging patterns
- Integration gotchas
- Deployment caveats
- Billing or webhook edge cases

## Bad Uses
- Temporary hacks
- Outdated architecture notes
- Full session transcripts
- Sensitive data
