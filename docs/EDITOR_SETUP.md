# EDITOR_SETUP.md

Recommended editor baseline for SaaS projects.

## Required VS Code Extensions

### AI And Agent Development
- GitHub Copilot
- GitHub Copilot Chat
- GitHub Pull Requests
- GitHub Actions

### Frontend And UI
- ESLint
- Prettier
- Tailwind CSS IntelliSense
- TypeScript and JavaScript Language Features
- PostCSS Language Support
- Auto Rename Tag
- Error Lens

### Backend And Database
- Prisma
- PostgreSQL or SQLTools, or the preferred database client
- Docker
- Dev Containers
- REST Client or Thunder Client

### Tests
- Playwright Test
- Vitest
- Jest Runner, if Jest is used

### Git And Productivity
- GitLens
- Conventional Commits
- Todo Tree
- Markdown All in One
- YAML
- DotENV

### Design
- Figma for VS Code, if used
- Iconify IntelliSense
- SVG Preview

## Policy
- Keep the extension baseline lean and practical.
- Prefer extensions that improve safety, verification, or speed.
- Avoid extension sprawl in templates meant for many future projects.
- If the team standardizes on another editor, keep this file as the baseline reference and mirror the same capabilities there.
