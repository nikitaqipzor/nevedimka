# План запуска: что подключить и где зарегистрироваться

Полная инструкция по шагам — в `LAUNCH_GUIDE.md`. Здесь — отдельно и
чётко: список всего, что нужно завести во внешних сервисах, разделённый
на обязательное и опциональное.

---

## Обязательно (без этого не запустится вообще)

### 1. Telegram-бот
**Где**: в Telegram написать **@BotFather** → `/newbot` → дать имя и
username (должен заканчиваться на `bot`).
**Получите**: токен вида `123456789:AAH...`
**Вписать в `.env`**: `TELEGRAM_BOT_TOKEN`

### 2. Свой Telegram ID
**Где**: написать **@userinfobot** в Telegram — ответит мгновенно.
**Получите**: числовой ID вида `700111222`
**Вписать в `.env`**: `OWNER_TELEGRAM_ID`
**Зачем обязательно**: без этого бот отвечает любому, кто его найдёт, а не
только вам.

### 3. Ключ Anthropic (для всех AI-функций — планировщик дня, наставник,
редактор текста и т.д.)
**Где**: [console.anthropic.com](https://console.anthropic.com) → API
Keys → Create Key.
**Вписать в `.env`**: `ANTHROPIC_API_KEY`
**Стоит денег** — по фактическому использованию токенов. Rate limit в
коде (`AI_RATE_LIMIT_MAX_CALLS=40` в час) защищает от случайного перерасхода.

### 4. База данных Postgres
Три варианта на выбор — нужен только один:

| Вариант | Где | Плюс |
|---|---|---|
| Бесплатный хостинг | [neon.tech](https://neon.tech) или [supabase.com](https://supabase.com) | Ничего не устанавливать локально, готово за 2 минуты |
| Docker | не нужна регистрация | `docker run postgres:16` или через `docker-compose.yml` в проекте |
| Локально | не нужна регистрация | `apt install postgresql` / `brew install postgresql` |

**Вписать в `.env`**: `DATABASE_URL`

### 5. Секрет для Mini App
**Регистрация не нужна** — просто сгенерировать случайную строку:
```bash
openssl rand -hex 32
```
**Вписать в `.env`**: `JWT_SECRET`

## Опционально (можно подключить позже, по одному)

### 6. Канал для публикации прогресса
**Где**: создать закрытый канал в Telegram → добавить своего бота
администратором с правом публикации сообщений.
**Дальше не нужно лезть в `.env`** — подключается прямо в приложении:
`/settings` в Mini App или боте → вписать `@username` канала → бот сам
проверит права и пришлёт тестовое сообщение.

### 7. Ключ OpenAI — для расшифровки речи (субтитры видео + автоматическая
расшифровка голосовых отчётов)
**Где**: [platform.openai.com](https://platform.openai.com) → API keys.
**Вписать в `.env`**: `ASR_API_KEY`
**Честно**: эта интеграция проверена только на моках, не на реальном
OpenAI API — см. `README.md`, раздел про ASR. Без этого ключа всё
остальное работает точно так же, просто без расшифровки.
**Без регистрации, но потребует времени на настройку** — self-hosted
альтернатива (whisper.cpp) существует и не требует платного API, но
не входит в готовый код, только задокументирована как вариант замены.

### 8. Публичный HTTPS-адрес для Mini App внутри Telegram
Нужен, только если хотите открывать Mini App кнопкой меню прямо в чате с
ботом (не просто в браузере). Два варианта:

- **Быстро, для проверки**: `ngrok` — регистрация не нужна для базового
  использования (`npx ngrok http 3000` даёт временный адрес).
- **Постоянно**: любой хостинг с поддержкой Node.js и HTTPS — Railway,
  Render, Fly.io, обычный VPS. Конкретный выбор не принципиален для
  проекта — важно только, чтобы адрес был публичным HTTPS.

Полученный адрес → `APP_BASE_URL` в `.env`, и у @BotFather:
`/mybots` → бот → Bot Settings → Menu Button.

## Ничего из этого регистрировать не нужно

Для полноты — на случай, если ищете:
- **Docker Hub / registry** — не нужен, `docker-compose.yml` собирает
  образы локально.
- **GitHub Actions** — уже настроен в `.github/workflows/ci.yml`, работает
  автоматически при пуше в свой репозиторий, отдельная регистрация не
  требуется (кроме самого GitHub, если ещё не используете).
- **Supabase Auth, Firebase и подобное** — авторизация уже полностью
  реализована через Telegram `initData`, ничего дополнительного не нужно.

## Итоговый список для копирования в `.env`

```bash
# обязательно
TELEGRAM_BOT_TOKEN=
OWNER_TELEGRAM_ID=
ANTHROPIC_API_KEY=
DATABASE_URL=
JWT_SECRET=

# опционально — можно оставить пустыми на старте
ASR_API_KEY=
APP_BASE_URL=http://localhost:3000
```

Полный `.env.example` в архиве проекта содержит ещё несколько технических
переменных (порты, лимиты воркера, тестовые заглушки) — у всех есть
разумные значения по умолчанию, трогать не обязательно.
